## 2026-11-04 — M1 Pilot, telemetry and native replay

Created `feat/m1-pilot` from synchronized `main` (`374ceec`) after PR #8 merged. Backed up and preserved the existing uncommitted `docs/02-agent.md` edits byte for byte. No project specification or README changes are included.

Implemented the Level 1 pixel-only Muse Spark loop with `act`, `note`, `report_issue`, and `finish`; strict action validation; text-only repeat warnings; request/decision/tic/USD/wall-clock bounds; bounded API retries; stateless encrypted reasoning replay; narrow session/observation types; eval-only telemetry with sector geometry and coarse-grid distances; `.lmp` recording; and native H.264 MP4 replay. SAM is absent from M1 and is not assumed to support independent text localization. M2–M5 remain unimplemented.

Validation: 54 offline tests passed in 5.63 seconds, including all four required M1 test files. Lint and whitespace checks passed. Two real `my_way_home`, L1, seed-101 runs are retained: the initial runtime validation reached `max_decisions` with 60 act calls (USD 0.248436); the final committed-code validation reached `budget_exhausted` with 57 act calls (USD 0.253330, including the final unexecuted response). Neither completed the level. Every one of the final run's 68 executed primitives matches a model act; zero API errors occurred. One invalid tool response was rejected in the first run and seven in the final run, without clamping or fallback actions.

Both 1280×720 H.264 replays are readable and match terminal telemetry: first run tic 841 / reward −0.0831, final run tic 760 / reward −0.0750 (reward tolerance 1e-8). The scenario's actual startup tic is 10; forcing tic 1 leaves early controls ineffective. Early demo flushes also append a native trailer tic, so replay uses the logged action interval as its pre-init timeout. The specification was not rewritten to hide these engine findings.

Limits: a response can cross the USD threshold before its usage is known; no action executes afterward. Coarse 128-unit BFS is unresolved for the observed cells and remains `null` with an explicit status. Collision estimates retain the M0 acceleration proxy rather than claiming steady-state precision. These are engineering smoke runs, not human-playability or completion-rate results. See [m1-results.md](m1-results.md) and [m1-evidence.json](m1-evidence.json) for sanitized measurements, provenance, action audits, and artifact hashes. Raw recordings and MP4s remain local under ignored `runs/`.
